How to use the seating plan

Your plan lives inside this file. Edit freely, then click Save to download an updated copy — that copy is the one to keep or send.

Seat a guest

  • Drag a name from the left list onto any seat (plan) or cell (table view) to seat them.
  • Drag seat → seat to move someone; dropping onto an occupied seat swaps the two.
  • Click a seated person to unseat them (they return to the list).
  • Colored dots mark each party / group; italic names are placeholders.
  • Guests who haven't confirmed their RSVP show a dotted seat outline on the plan, and a hollow dotted dot in the lists.

Left panel — guests

  • Search — type a name, then click a result to fly the plan to their seat.
  • Add guest + Party — adds a new person to the unseated list (Party is optional, and colors them).
  • × on a guest row deletes them entirely.
  • Unseated only — hide everyone who already has a seat.

Plan view — moving around

  • Drag empty floor to pan; scroll to pan; Ctrl/⌘ + scroll to zoom.
  • − / + zoom; click the percentage to fit everything on screen.
  • Drag a table's center circle to reposition it (rooms are outlined guides).
  • Click a table's center to select it — a small toolbar lets you set the seat count, Rename, switch Round/Oval, ⇄ Swap all its guests with another table (click the other table after pressing it), or delete it.
  • Swap two whole tables in Table view: drag one table's name onto another's.

Toolbar buttons

  • Plan / Table — switch between the graphic floor plan and a spreadsheet of rooms → tables → seats.
  • Auto-seat — drop all unseated guests into open seats, keeping parties together.
  • Clear seats — empty every seat (the guest list is kept).
  • Save — the first time, your browser asks where to keep the file (keep the suggested name and place, or pick the file you opened to update it). After that, Save writes straight to that file — just press Allow if the browser asks once. The button turns blue when there are unsaved changes.
  • Save to a different file — hold Shift while clicking Save to choose a new name or location; saves then go there.
  • Discard changes — appears only when something is unsaved; puts everything back to the file's last saved version.
  • To print, use the browser's print (Ctrl+P) — the current view prints cleanly.

Saving & sharing

  • The plan is stored inside the file itself. In Chrome or Edge, Save updates your file directly — no copies pile up. The version date at the top-left shows when it was last saved.
  • To share: click Save, then email or message the file. Whoever opens it sees exactly what you saved, on any computer.
  • On browsers without direct saving, Save downloads a fresh copy named with the date and time instead — the newest dated file is then the latest plan.
  • If you close without saving, this browser remembers your edits and brings them back next time — but only on this computer, so always Save before sharing.
